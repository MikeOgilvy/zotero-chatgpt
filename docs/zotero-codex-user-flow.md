# Zotero Codex Reader 产品规格

2026-09-11。本文件是唯一产品行为与验收权威，替代旧 selected-text-only 默认范围。实现程度见 [progress](progress.md)，机制见 [module-design](module-design.md)。本文所有“应”均是验收要求，不是完成声明。

## 定位与范围

ZCR 是深度融入 Zotero 的 Codex 文献阅读与整理 agent。聊天承接任务与共同思考，成果进入文献工作流。独立社区身份不暗示官方出品。优先统一设计、交互细节、可靠性、性能，不建设多供应商平台或独立网页壳。

## 安装、登录、更新

一个完整平台 XPI → Zotero 原生安装 → Sign in with ChatGPT → 回到当前文章。无需 Node/CLI/终端/companion/复制 token。插件校验并准备运行组件，显示真实阶段和可操作失败原因。

官方授权使用系统浏览器与插件专用受保护账户目录，不读取其他客户端凭据。区分成功、取消、网络失败、过期、模型不可用与限额；重登保留草稿、历史和原意图且不重复发送。不强制教程或 personalization 问卷。打开 sidebar 不生成模型请求。

升级保留数据与在途任务，迁移失败不重置。单包下载、平台安全、无 Node 环境、升级回退必须在真实发行物上验证；支持范围由验收决定。

## 原生界面与选区

2026-09-12 UI 方向：参考本机 Cursor 中官方 Codex 扩展的精细程度，以单会话标题、统一候选弹层、自然布局的 composer、可见键盘焦点和低对比层次实现。顶部不堆会话标签和删除 X；历史/管理操作按需打开，正文增长不能覆盖消息。

2026-09-14 UI 决策：会话不再有独立的三点菜单——重命名落在会话标题本身，账户用量移入模型选择器；新建与历史入口靠右；附件弹层只保留图片与区域截图，区域截图另有一个独立按钮；reference 与 skill 是两个分开的入口；所有面向用户的 “workflow” 一律称 “skill”，存储 schema、id 与 skill 名称逐字不变；历史记录直接删除、不再二次确认（删除仍与停止、撤销、删除文献互相独立）。

2026-09-14 并行会话决策（修订上一条“顶部不堆会话标签”）：同一附件可同时打开多个会话，新会话不再顶掉屏幕上的会话；dock 一次只有一个会话是可编辑面板（composer、任务、滚动按会话各自保存）。打开的会话以标题条（switcher）呈现，**仅当多于一个会话时出现**，窄 dock 在条内横向滚动、标题截断；条上标记当前会话，方向键与 Home/End 只在会话间移动焦点而不激活（浏览不改变正在编辑的会话），Enter/Space 才切换。关闭面板回到仍打开的另一个会话（按打开顺序取最近的一个），关闭最后一个才回到新建态；关闭与删除都不动磁盘上的其他会话，存储的 `current` 指针仍只记录最近恢复的那一个。

2026-09-14 两列只读转录决策（option B，**已于 2026-09-15 作废**）：当 dock **实测**宽度容得下两列各自可读的聊天时，标题条之外并排显示另一个打开会话的只读转录。该形状被拒绝：Cursor Agent 是标签切换，不是并排两个转录。

2026-09-15 UI 决策（修订标题条与附件，对齐 Cursor Agent 标签）：chrome **始终**显示会话标签。已打开的命名会话在左。首次打开、条上还没有命名会话时，未发送的 composer 标签**立刻**显示条目完整标题（缺失则附件/文件名），不为此建记录；输入区与标题同时出现，不等连接或解析。`+` 在已有命名会话旁打开的才是 **New chat** 文案，切到其它会话后仍留在条上，直到关闭或第一次发送把它变成记录；选中标签才显示关闭 X；`+` 与历史时钟靠右。`+` 在已位于未发送标签时是空操作。关闭 New chat 回到仍打开的命名会话；关闭最后一个命名会话回到未发送标签（再次显示文章标题）。空聊天不进历史。附件弹层只保留 **Attach file**（原生多选，文本或 PNG/JPEG/GIF/WebP）；删除“Choose images”和“Capture selected region”（后者只是把上次文字选区矩形栅格化，不是截图工具）。附图路径是文件选择、拖放和剪贴板粘贴。

2026-09-15 两列撤销：dock **永不**并排两个转录。无论宽度、测量或聊天字号如何，都只有当前会话的一列；其它打开的会话只在标签条上。切换靠点标签。PDF 缩放与聊天字号仍相互独立。

默认四区：顶部对话/历史入口、紧凑上下文摘要、消息/任务主体、统一输入区。历史、完整上下文、skills、高级设置按需展开；不把工具数量变成常驻按钮。使用 Zotero 字体、浅深主题、灰阶、间距、控件尺度和可见键盘焦点；样式限制在插件区域。

入口位于 PDF 工具栏搜索左侧。助手在原生工具栏下方的阅读器右侧参与真实布局。避免覆盖正文和双侧栏挤压；用户切换原生信息/笔记时让出，关闭时只恢复仍归插件所有的旧状态。

选区上方提供 More details（直接解释）与 Ask in sidechat（仅加入选区、聚焦、等待发送）；原生颜色/高亮/下划线继续工作。操作前冻结选区/来源，避让原生菜单和视口边缘，可关闭；重复点击、失焦、切文献不得发送过期内容。界面与回答语言独立；键盘可走主要流程，图标有名称，状态不只靠颜色，支持减少动态效果。

## 当前 PDF 默认上下文

默认“全文背景＋当前选区＋用户问题”。无需上传或 @ 当前 PDF，只纳入当前附件；其他标签和整库不自动进入范围。打开 PDF 可低优先本地准备；标题、历史、输入区立即出现，不等解析。只有用户请求/任务授权才外发。首次启用说明全文文本/图像的数据范围，之后不逐篇打断；提供关闭设置。侧栏显示 reader 实际读到的书目卡片（title/authors 与 Zotero 真声明过的其余字段），并显示**实际发生的本地读取**：全部可提取时说“读完 N 页”，仅部分页有文本时给出诚实分母，未启用本地读取时不报成读取。等待 reader 暴露 PDF 的时间须容得下真实大论文的正常加载，且可取消。

普通文献在实际预算可容纳时纳入所有可提取文本，保留章节、图注、页码和段落位置；预算预留指令、历史、skills、图像和输出。不得任意截断后声称全文。需要图表、复杂公式时读取对应图像及正文；全文文本发送不代表所有图表已理解。

长文献/书籍按章节和问题范围读取或检索，明确实际覆盖；全书问题不得只读摘要。扫描页/解析失败如实列出，必要范围再考虑 OCR；外部解析服务须授权。发送时尚未准备完成则接受并保留问题，显示真实进度、可取消，不能无上下文偷发。

每次发送冻结文献/附件/profile/library、文件版本、选区、问题、引用、skill、模型设置、权限。切标签不能改变归属。解析缓存用稳定身份＋内容版本＋解析器版本，替换文件失效；不在 UI 线程每轮全文 hash。容量有边界，按需调度，不同时解析所有标签。

后续轮次复用会话/文献状态，不机械追加多份全文。压缩、截断、恢复后按需重新取证；本地缓存不代表上游免计费或永久常驻。不能获取实际容量时明确未知；估算与实测分开。

## 会话、历史与请求

首次打开直接用条目完整标题，缺失时附件/文件名；该标题出现在未发送标签上，视觉可截断，完整名称可查看复制搜索。恢复本文最近对话，不重复建空会话；显式新建是未持久化的 New chat 标签，第一次发送才建记录，存储标题就是文章标题。同名会话只在标签条上显示 `标题 · 2` 这类序号，已有的存储标题是数据、永不重写；改名不被元数据更新覆盖，也不被新建会话重写。无内容的临时会话不污染历史，有草稿保留。

用稳定 ID，不能以标题/文件名/运行时数值 ID 作为唯一身份。同名、正文/补充材料隔离；修改标题不丢会话。历史搜索原文章标题、改名、消息，显示作者/年份/附件/最近时间，可恢复并打开文献。

草稿、引用、设置、消息与滚动按文章和会话保存；明确重启恢复范围。关闭 view 不结束任务；多窗口一致、不重复发。编辑旧问题保留分支；重新生成不重放写入。生成中能输入，明确补充与下轮排队；未支持即时干预时只能如实排队。

requestId 和状态可靠持久化，双击不重发。不确定结果先对账，停止等待真实确认。删除聊天、停止、撤销与删除文献互相独立。离线能查看已有本地历史/成果，失败保留草稿。

## @ 引用与 /skill

@ 引用对象，/ 选择 skill；加入或选择本身不发送、不写入。核心包含 @文章、@chat、/skill、已安装 skill 的直接调用。统一自动补全、类型筛选和拖拽语义，方向键/Enter/Escape 一致，确认候选不能发送。

候选区分同名：文章显示作者/年份/附件；聊天显示关联文章/时间。引用可预览、调整范围、移除。@chat 默认指定消息或清楚标记的摘要快照，不递归展开嵌套引用；回答只作背景，不作文献证据。先支持插件内聊天，不承诺全 ChatGPT/Codex 历史。

collection、笔记、标注可扩展为统一范围对象；选择集合不代表已全部读取，不各建一套常驻面板。

## Personalization 与 skills

全局偏好、对话明确选定研究主题、当前消息/对话覆盖三层；含语言、详细程度、数学解释、背景、引用/笔记/标注风格。明确指令优先于表达偏好，不能改变权限。多 collection 不自动叠加冲突配置。可查看、修改、关闭、导出；初期只接受明确设置，不偷偷记忆。

Skill 描述输入、步骤、工具、输出和限制；统一 / 入口支持推导、精读标注、比较、获取整理。尽量兼容 SKILL.md，按固定版本核验执行能力，不把文件格式兼容说成任意脚本可运行。支持创建/编辑/复制/启停/导入/导出/试运行，有 UI 与高级文件入口。显示来源、版本、依赖、权限；导入不自动运行或扩权。本轮冻结版本，按需加载。

## 模型与多模态

模型、推理强度、服务档位、回答详细程度、任务范围与权限各自独立。动态发现真实能力；不支持则说明原因，不做假档位，不静默降级或改变计费。生成中改设置仅下一轮生效；历史可检查本轮配置。额度/占用显示精确、估算或未知。

支持文字、公式、图像、表格：粘贴、拖拽、文件选择（文本或图片）、多图＋文字；发送前预览/删除/排序/放大。图像保留来源/图注/必要正文，不压到不可辨认；临时图片与导入 Zotero 分开。剪贴板截图须附加成功或给出诚实拒绝（过大或非 PNG/JPEG/GIF/WebP）；macOS TIFF 仅在能转为 PNG 时附加。

输出渲染 Markdown、数学、表格、代码、可定位引用和图像；复制可用 LaTeX/表格。生成示意图与原文图区分。图像生成是目标能力，不能以读图代替；接通服务/数据/费用需必要授权，未接通不能伪造成果。实时语音视频/任意格式不是首轮必需。

## 上下文与 agent 成果

摘要展开后分别显示：允许访问、已本地解析、本轮发送、已引用证据；包括页章、图像、聊天范围、偏好/skill、缺口/压缩。可查看实际资料清单和可见发送内容，不伪造内部隐藏提示。可限制/移除/固定来源，移除只影响后续引入，不抹去已发送历史；可据选定资料新开对话。

阅读回答区分原文、教学补充、推测，并能回到证据。临时聊天不自动堆笔记。

自动标注按阅读目标选择定义、假设、方法、推导、证据和局限；先候选/原文定位/逐项排除，任务级批准后写 Zotero 原生标注。程序核对真实片段和坐标，定位不可靠只建议；AI 来源可识别，保留人工标注。书籍报告覆盖和遗漏，不以高亮数代替质量。

获取整理按明确 DOI/链接/列表执行：识别→核对元数据→查重→合法全文→对应/版本验证→指定 collection→报告。优先宿主机制，不让模型任意脚本操作库。拒绝登录页/错误 PDF/误认补充材料；失败保留正确元数据、如实报告，不绕访问控制，不擅自建标签/移动全库/删除/合并。

阅读、标注、获取使用统一范围/进度/审批/结果/错误 UI。读在已授权范围内连续进行；写使用任务级或明确有限规则。实际写入单独记账；中断列已完成/未执行/不确定，重试只补未完成，撤销持久化且不覆盖后续人工编辑。

## 交互、性能、安全验收

PDF 缩放、聊天字号、控件尺度独立。真实 dock 保持当前 PDF 坐标锚点；固定缩放暂时适配，手动改后尊重新值，关闭保留当前段落。宽表/长公式局部滚动，大字号/窄窗/多显示器/主题不溢出。中文 IME 确认不发送；输入有限高；图像处理/生成时仍能输入、翻页、拖动；流式不抢焦点/滚动/选区，未闭合公式稳定过渡。快捷键不全局劫持。

初始性能门槛：普通本地交互 p95 ≤100ms；缓存 sidebar 打开可交互 p95 ≤250ms。按设备、数据、版本、样本量分别测冷/暖启动、准备、模型等待、渲染；即时反馈不冒充操作完成，不能只报均值。长期开关/切换无无界内存增长或持续退化；稳定消息不每 token 重绘，历史按需加载，关键状态可靠持久化。

正文、图像、历史、网页、第三方 skill 均不可信；参数校验、路径范围与写入审批由代码执行，生成内容不执行脚本/任意本地资源。外发范围准确说明，诊断无正文/凭据/账户/私人路径。账户、缓存、历史、原生标注职责分离，退出/清缓存/卸载不混同。附件替换/合并/删除检查引用。数据迁移/损坏/回退/多窗口用隔离资料验证，未实现同步不承诺。

关键门槛还包括：干净登录；全文直接问/选区背景；发送后切附件；同名隔离；关闭恢复/改名可搜；@chat 无递归；设置/skill 冻结；长文覆盖/扫描缺口；压缩后取证/替换失效；停止重启不重写；撤销保护人工；下载失败不报成功；生成图区分原文。各自执行证据统一记录在 progress。
