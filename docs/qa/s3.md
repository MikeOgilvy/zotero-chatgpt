## Regressions resolved during the host loop

- Gecko refuses chrome callbacks invoked as content-array `map`/`every`. `captureSelection` now copies rects by index; a unit test poisons those methods.
- `PDFView._handlePointerDown` returns immediately for `pointerType === 'mouse'`. The host driver drives the view handlers with content-compartment objects that omit `pointerType`.
- Switching reader tabs called `nativeAction()` on the unselected reader, which closed its chat. Reconcile now unmounts only the view and remounts when that reader is selected again.

## Assertion change (2026-09-10, source only)

More details still records one explain user message and keeps the citation in chrome, but the visible transcript/composer must not show `tell me more about this` or the old Chinese preset. The table above is the earlier host run; that run was **not** repeated after the driver rewrite.

## Boundaries and next stage

This remains a **development preview**. Answers are plain text. Model/speed/reasoning controls, Markdown/KaTeX, edge-avoiding bar geometry and multi-conversation history are S4/S5. Follow-up on the same thread is implemented and unit-tested; the host could not observe a second turn because the first explain was refused.

Reproduction commands are in [development.md](../development.md). Leave the dedicated Zotero window untouched while a host run is in progress.
