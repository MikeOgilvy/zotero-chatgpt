Date: 2026-09-08. Scope: native reader shell and development packaging only.

- XPI: `dist/zotero-codex-reader-0.1.0a2-dev.xpi`; npm workspace version `0.1.0-alpha.2`.

It waits for Zotero's asynchronous bootstrap and observer cleanup, which can finish after AddonManager's promise resolves.

## Regressions resolved

- Native Fluent localization applied to the entire collapsible section replaced its chat body. The title now supplies only `.label` and `.tooltiptext` attributes. This fixes the report that the Codex and native context buttons looked equivalent.
- Numeric destination zoom is ignored by this Zotero viewer. Fixed zoom restoration now uses the native viewer scale setter.
- Link navigation can register delayed text-layer focus callbacks that jump to an old page after resizing. Layout compensation now scrolls through the native PDF viewer directly and preserves the current reading anchor.
- Startup/window-hook overlap, rapid sidebar reopening and timezone-dependent ZIP timestamps have regression coverage.

## Boundaries and next stage

This is a **development preview**, displaying attachment information and an explicit “No model connected” notice. ChatGPT login, Codex execution, selection actions, model/speed/reasoning controls, message streaming and history are not implemented. S2 introduces runtime/login; S3 introduces selection-to-chat.

The checks establish the basic native dock and lifecycle on this host. They do not constitute the complete A01–A30 release acceptance suite. Split-reader and standalone-reader windows, stacked layout, dark theme, narrow-window edge cases, drag-resizing, production download/upgrade behavior and additional host/platform versions remain outside this S1 verification. The current adapter does not activate in unsupported standalone/stacked layouts.

Reproduction commands and isolated-profile setup are in [development.md](../development.md). A successful host run uninstalls the subject addon from the disposable test profile; run the preparation script again before another run.
