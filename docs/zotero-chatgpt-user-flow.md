# Zotero ChatGPT 产品规格

2026-09-11。本文件是唯一产品行为与验收权威，替代旧 selected-text-only 默认范围。实现程度见 [progress](progress.md)，机制见 [module-design](module-design.md)。本文所有“应”均是验收要求，不是完成声明。

## 定位与范围

Zotero ChatGPT 是深度融入 Zotero 的 GPT 式文献阅读与问答产品：自动以当前 PDF 为上下文，回答论文问题，支持公式、图表、引用、会话、历史与多模态输入，并与 Zotero 自然集成。独立社区身份不暗示官方出品。优先统一设计、交互细节、可靠性、性能，不建设多供应商平台或独立网页壳。

2026-09-18 模式架构决策：产品主体由共享文档上下文之上的**两种模式**组成，agent 动作只是叠加在 Chat Mode 之上的可选能力。

- **Chat Mode（对话阅读器）**：轻量对话式读论文。自动使用当前打开的 PDF，回答问题，解释文字、图表、方法、公式与概念，总结段落或全文；以当前页/选区/邻近文本为即时上下文，必要时从全文检索相关段落，并可做只读的 Zotero/文献库搜索。只读：不修改 Zotero 数据或文件、不创建标注/高亮、不执行多步动作，且不计入 Agent/动作额度。
- **Agent Mode（可动作阅读器）**：在与 Chat Mode 完全相同的自动 PDF 上下文之上，可显式调用工具与多步动作（创建/编辑标注、高亮、建笔记、改元数据、整理条目/集合、检索/下载文献、修改被许可的文件），并在适用处使用审批 / 动作账本 / 撤销 / 对账。动作仍以确定性校验 / 原生执行作为安全边界，模型不获得通用脚本或任意文件系统工具。可消耗 Agent/动作额度。

概念上：Chat Mode 是 `用户 → 文档上下文 → LLM → 回答`；Agent Mode 是 `用户 → 文档上下文 → agent → 工具/动作 → 结果`。

**Chat Mode 是完整的一等产品，不是弱化的 Agent Mode。** 产品定位是“一个 ChatGPT 式的论文阅读侧栏，Agent Mode 是可选的、作用于 Zotero 与文件的能力”。

模式分层不定义产品主体，也不改变默认阅读路径；未取得证据的自主动作不按已完成描述。

## 安装、登录、更新

一个完整平台 XPI → Zotero 原生安装 → Sign in with ChatGPT → 回到当前文章。无需 Node/CLI/终端/companion/复制 token。插件校验并准备运行组件，显示真实阶段和可操作失败原因。

官方授权使用系统浏览器与插件专用受保护账户目录，不读取其他客户端凭据。区分成功、取消、网络失败、过期、模型不可用与限额；重登保留草稿、历史和原意图且不重复发送。不强制教程或 personalization 问卷。打开 sidebar 不生成模型请求。

升级保留数据与在途任务，迁移失败不重置。单包下载、平台安全、无 Node 环境、升级回退必须在真实发行物上验证；支持范围由验收决定。

## 原生界面与选区

2026-09-12 UI 方向：参考本机 Cursor 中官方 Codex 扩展的精细程度，以单会话标题、统一候选弹层、自然布局的 composer、可见键盘焦点和低对比层次实现。顶部不堆会话标签和删除 X；历史/管理操作按需打开，正文增长不能覆盖消息。

2026-09-14 UI 决策：会话不再有独立的三点菜单——重命名落在会话标题本身，账户用量移入模型选择器；新建与历史入口靠右；附件弹层只保留图片与区域截图，区域截图另有一个独立按钮；reference 与 skill 是两个分开的入口；所有面向用户的 “workflow” 一律称 “skill”，存储 schema、id 与 skill 名称逐字不变；历史记录直接删除、不再二次确认（删除仍与停止、撤销、删除文献互相独立）。

2026-09-14 并行会话决策（修订上一条“顶部不堆会话标签”）：同一附件可同时打开多个会话，新会话不再顶掉屏幕上的会话；dock 一次只有一个会话是可编辑面板（composer、任务、滚动按会话各自保存）。打开的会话以标题条（switcher）呈现，**仅当多于一个会话时出现**，窄 dock 在条内横向滚动、标题截断；条上标记当前会话，方向键与 Home/End 只在会话间移动焦点而不激活（浏览不改变正在编辑的会话），Enter/Space 才切换。关闭面板回到仍打开的另一个会话（按打开顺序取最近的一个），关闭最后一个才回到新建态；关闭与删除都不动磁盘上的其他会话，存储的 `current` 指针仍只记录最近恢复的那一个。

2026-09-14 两列只读转录决策（option B，**已于 2026-09-15 作废**）：当 dock **实测**宽度容得下两列各自可读的聊天时，标题条之外并排显示另一个打开会话的只读转录。该形状被拒绝：Cursor Agent 是标签切换，不是并排两个转录。

2026-09-15 UI 决策（修订标题条与附件，对齐 Cursor Agent 标签；其中“首次打开未发送标签显示文章标题”一条已于 2026-09-18 撤销，见下）：chrome **始终**显示会话标签。已打开的命名会话在左。首次打开、条上还没有命名会话时，未发送的 composer 标签**立刻**显示条目完整标题（缺失则附件/文件名），不为此建记录；输入区与标题同时出现，不等连接或解析。`+` 在已有命名会话旁打开的才是 **New chat** 文案，切到其它会话后仍留在条上，直到关闭或第一次发送把它变成记录；选中标签才显示关闭 X；`+` 与历史时钟靠右。`+` 在已位于未发送标签时是空操作。关闭 New chat 回到仍打开的命名会话；关闭最后一个命名会话回到未发送标签（再次显示文章标题）。空聊天不进历史。附件弹层只保留 **Attach file**（原生多选，文本或 PNG/JPEG/GIF/WebP）；删除“Choose images”和“Capture selected region”（后者只是把上次文字选区矩形栅格化，不是截图工具）。附图路径是文件选择、拖放和剪贴板粘贴。

2026-09-18 UI 决策（撤销上一条的标题要求）：未发送的临时会话只叫 **New chat**；若处于 Agent Mode，也可叫 **New agent**。不要求未发送标签显示文章标题或文件名，标签文字不承担文章身份；文章身份与上下文只由附件/上下文系统提供。输入区仍在首次打开时立刻可写，不等连接或解析。空聊天仍不进历史，第一次发送才建记录；标题条其余行为不变。

2026-09-15 两列撤销：dock **永不**并排两个转录。无论宽度、测量或聊天字号如何，都只有当前会话的一列；其它打开的会话只在标签条上。切换靠点标签。PDF 缩放与聊天字号仍相互独立。

默认四区：顶部对话/历史入口、紧凑上下文摘要、消息/任务主体、统一输入区。历史、完整上下文、skills、高级设置按需展开；不把工具数量变成常驻按钮。使用 Zotero 字体、浅深主题、灰阶、间距、控件尺度和可见键盘焦点；样式限制在插件区域。

入口位于 PDF 工具栏搜索左侧。助手在原生工具栏下方的阅读器右侧参与真实布局。避免覆盖正文和双侧栏挤压；用户切换原生信息/笔记时让出，关闭时只恢复仍归插件所有的旧状态。

选区上方提供 More details（直接解释）与 Ask in sidechat（仅加入选区、聚焦、等待发送）；原生颜色/高亮/下划线继续工作。操作前冻结选区/来源，避让原生菜单和视口边缘，可关闭；重复点击、失焦、切文献不得发送过期内容。界面与回答语言独立；键盘可走主要流程，图标有名称，状态不只靠颜色，支持减少动态效果。

## 当前 PDF 默认上下文

### 产品不变式：当前 PDF 是隐式上下文

> 当前打开的 PDF 是隐式上下文，不是手动附加的文件。（The currently opened PDF is implicit context, not a manually attached file.）

只要 Zotero Reader 中存在当前打开的 PDF，它在两种模式下都自动成为默认上下文；用户不需要手动上传、附加或 @ 当前 PDF。没有当前 PDF 时，才退化为显式 @ 引用或手动附件。

### 共享文档上下文层

不为 Chat Mode 与 Agent Mode 各建一套 Reader 管道；两种模式共用同一个文档上下文层：

```text
Reader
 → Current Document Context
    - Zotero 条目元数据 / 书目字段
    - 附件身份与文件版本
    - PDF 文本（页、段落、来源）
    - 当前页
    - 当前选区
    - 邻近文本
    - 标注
    - 引用与页定位信息
 → Chat Mode 或 Agent Mode
```

上下文分层取用，不要求每轮都整篇发送：

1. **始终可用的轻量元数据**：条目类型、标题、作者、年份、期刊、DOI 等 Zotero 真声明过的书目字段（与侧栏书目卡片、请求里的紧凑书目块共用同一份清单）。
2. **即时 reader 上下文**：当前页、可见/选中文本、邻近段落。
3. **按需全文检索/读取**：问题需要时从全文检索相关段落，或生成聚焦/多轮阅读计划；只有预算可容纳且策略允许时才纳入全部可提取文本。

每层都保留来源关联、物理页号、印刷页标签与实际覆盖；“已发送”不等于“已理解全部图表”，估算与实测分开。

默认“全文背景＋当前选区＋用户问题”。无需上传或 @ 当前 PDF，只纳入当前附件；其他标签和整库不自动进入范围。打开 PDF 可低优先本地准备；未发送会话、历史、输入区立即出现，不等解析。只有用户请求/任务授权才外发。首次启用说明全文文本/图像的数据范围，之后不逐篇打断；提供关闭设置。侧栏显示 reader 实际读到的书目卡片（title/authors 与 Zotero 真声明过的其余字段），并显示**实际发生的本地读取**：全部可提取时说“读完 N 页”，仅部分页有文本时给出诚实分母，未启用本地读取时不报成读取。等待 reader 暴露 PDF 的时间须容得下真实大论文的正常加载，且可取消。

普通文献在实际预算可容纳时纳入所有可提取文本，保留章节、图注、页码和段落位置；预算预留指令、历史、skills、图像和输出。不得任意截断后声称全文。需要图表、复杂公式时读取对应图像及正文；全文文本发送不代表所有图表已理解。

长文献/书籍按章节和问题范围读取或检索，明确实际覆盖；全书问题不得只读摘要。扫描页/解析失败如实列出，必要范围再考虑 OCR；外部解析服务须授权。发送时尚未准备完成则接受并保留问题，显示真实进度、可取消，不能无上下文偷发。

每次发送冻结模式（Chat Mode / Agent Mode）、文献/附件/profile/library、文件版本、选区、问题、引用、skill、模型设置、权限。切标签不能改变归属。解析缓存用稳定身份＋内容版本＋解析器版本，替换文件失效；不在 UI 线程每轮全文 hash。容量有边界，按需调度，不同时解析所有标签。

后续轮次复用会话/文献状态，不机械追加多份全文。压缩、截断、恢复后按需重新取证；本地缓存不代表上游免计费或永久常驻。不能获取实际容量时明确未知；估算与实测分开。

## 会话、历史与请求

2026-09-18 模式会话决策：Chat Mode 与 Agent Mode **共用同一会话/会话记录**。示例：用户在 Chat Mode 问“哪些段落最重要？”，切到 Agent Mode 说“高亮这些段落并加简短笔记”，Agent 应复用先前对话与文档引用，而不是从零开始。模式是每轮请求冻结的设置之一（与 skill、权限、模型设置并列）；切换模式不新建聊天、不丢草稿、不重放写入，模式只决定该轮是否暴露工具/动作能力。未发送标签在 Chat Mode 下叫 New chat，在 Agent Mode 下可叫 New agent。

首次打开直接进入可写的未发送会话；恢复本文最近对话，不重复建空会话。未发送的临时会话不显示文章标题，只叫 New chat（Agent Mode 下可叫 New agent）；文章身份由附件/上下文系统提供，不依赖标签文字。显式新建同样是未持久化的 New chat 标签，第一次发送才建记录，存储标题就是文章标题。已发送会话标题视觉可截断，完整名称可查看复制搜索。同名会话只在标签条上显示 `标题 · 2` 这类序号，已有的存储标题是数据、永不重写；改名不被元数据更新覆盖，也不被新建会话重写。无内容的临时会话不污染历史，有草稿保留。

用稳定 ID，不能以标题/文件名/运行时数值 ID 作为唯一身份。同名、正文/补充材料隔离；修改标题不丢会话。历史搜索原文章标题、改名、消息，显示作者/年份/附件/最近时间，可恢复并打开文献。

草稿、引用、设置、消息与滚动按文章和会话保存；明确重启恢复范围。关闭 view 不结束任务；多窗口一致、不重复发。编辑旧问题保留分支；重新生成不重放写入。生成中能输入，明确补充与下轮排队；未支持即时干预时只能如实排队。

requestId 和状态可靠持久化，双击不重发。不确定结果先对账，停止等待真实确认。删除聊天、停止、撤销与删除文献互相独立。离线能查看已有本地历史/成果，失败保留草稿。

## @ 引用与 /skill

@ 引用对象，/ 选择 skill；加入或选择本身不发送、不写入。核心包含 @文章、@chat、/skill、已安装 skill 的直接调用。统一自动补全、类型筛选和拖拽语义，方向键/Enter/Escape 一致，确认候选不能发送。

候选区分同名：文章显示作者/年份/附件；聊天显示关联文章/时间。引用可预览、调整范围、移除。@chat 默认指定消息或清楚标记的摘要快照，不递归展开嵌套引用；回答只作背景，不作文献证据。先支持插件内聊天，不承诺全 ChatGPT/Codex 历史。

collection、笔记、标注可扩展为统一范围对象；选择集合不代表已全部读取，不各建一套常驻面板。

## Personalization 与 skills

全局偏好、对话明确选定研究主题、当前消息/对话覆盖三层；含语言、详细程度、数学解释、背景、引用/笔记/标注风格。明确指令优先于表达偏好，不能改变权限。多 collection 不自动叠加冲突配置。可查看、修改、关闭、导出；初期只接受明确设置，不偷偷记忆。

Skill 描述输入、步骤、工具、输出和限制；统一 / 入口支持推导、精读标注、比较、获取整理。尽量兼容 SKILL.md，按固定版本核验执行能力，不把文件格式兼容说成任意脚本可运行。支持创建/编辑/复制/启停/导入/导出/试运行，有 UI 与高级文件入口。显示来源、版本、依赖、权限；导入不自动运行或扩权。本轮冻结版本，按需加载。

## 模型与多模态

模型、推理强度、服务档位、回答详细程度、任务范围与权限各自独立。动态发现真实能力；不支持则说明原因，不做假档位，不静默降级或改变计费。生成中改设置仅下一轮生效；历史可检查本轮配置。额度/占用显示精确、估算或未知。

支持文字、公式、图像、表格：粘贴、拖拽、文件选择（文本或图片）、多图＋文字；发送前预览/删除/排序/放大。图像保留来源/图注/必要正文，不压到不可辨认；临时图片与导入 Zotero 分开。剪贴板截图须附加成功或给出诚实拒绝（过大或非 PNG/JPEG/GIF/WebP）；macOS TIFF 仅在能转为 PNG 时附加。

输出渲染 Markdown、数学、表格、代码、可定位引用和图像；复制可用 LaTeX/表格。生成示意图与原文图区分。图像生成是目标能力，不能以读图代替；接通服务/数据/费用需必要授权，未接通不能伪造成果。实时语音视频/任意格式不是首轮必需。

## 上下文与成果

以下上下文摘要属于共享文档上下文层，Chat Mode 与 Agent Mode 都读取它；本节后半的自动标注与获取整理只属于叠加在 Chat Mode 之上的 Agent Mode 能力。

摘要展开后分别显示：允许访问、已本地解析、本轮发送、已引用证据；包括页章、图像、聊天范围、偏好/skill、缺口/压缩。可查看实际资料清单和可见发送内容，不伪造内部隐藏提示。可限制/移除/固定来源，移除只影响后续引入，不抹去已发送历史；可据选定资料新开对话。

阅读回答区分原文、教学补充、推测，并能回到证据。临时聊天不自动堆笔记。

自动标注按阅读目标选择定义、假设、方法、推导、证据和局限；先候选/原文定位/逐项排除，任务级批准后写 Zotero 原生标注。程序核对真实片段和坐标，定位不可靠只建议；AI 来源可识别，保留人工标注。书籍报告覆盖和遗漏，不以高亮数代替质量。

获取整理按明确 DOI/链接/列表执行：识别→核对元数据→查重→合法全文→对应/版本验证→指定 collection→报告。优先宿主机制，不让模型任意脚本操作库。拒绝登录页/错误 PDF/误认补充材料；失败保留正确元数据、如实报告，不绕访问控制，不擅自建标签/移动全库/删除/合并。

阅读、标注、获取使用统一范围/进度/审批/结果/错误 UI。读在已授权范围内连续进行；写使用任务级或明确有限规则。实际写入单独记账；中断列已完成/未执行/不确定，重试只补未完成，撤销持久化且不覆盖后续人工编辑。

## 交互、性能、安全验收

PDF 缩放、聊天字号、控件尺度独立。真实 dock 保持当前 PDF 坐标锚点；固定缩放暂时适配，手动改后尊重新值，关闭保留当前段落。宽表/长公式局部滚动，大字号/窄窗/多显示器/主题不溢出。中文 IME 确认不发送；输入有限高；图像处理/生成时仍能输入、翻页、拖动；流式不抢焦点/滚动/选区，未闭合公式稳定过渡。快捷键不全局劫持。

初始性能门槛：普通本地交互 p95 ≤100ms；缓存 sidebar 打开可交互 p95 ≤250ms。按设备、数据、版本、样本量分别测冷/暖启动、准备、模型等待、渲染；即时反馈不冒充操作完成，不能只报均值。长期开关/切换无无界内存增长或持续退化；稳定消息不每 token 重绘，历史按需加载，关键状态可靠持久化。

正文、图像、历史、网页、第三方 skill 均不可信；参数校验、路径范围与写入审批由代码执行，生成内容不执行脚本/任意本地资源。外发范围准确说明，诊断无正文/凭据/账户/私人路径。账户、缓存、历史、原生标注职责分离，退出/清缓存/卸载不混同。附件替换/合并/删除检查引用。数据迁移/损坏/回退/多窗口用隔离资料验证，未实现同步不承诺。

关键门槛还包括：当前 PDF 自动成为两种模式的隐式上下文；Chat Mode 只读、无 Zotero/文件写入且不计入 Agent/动作额度；Chat Mode 与 Agent Mode 共用同一会话，切换模式后续用先前对话与文档引用；干净登录；全文直接问/选区背景；发送后切附件；同名隔离；关闭恢复/改名可搜；@chat 无递归；设置/skill 冻结；长文覆盖/扫描缺口；压缩后取证/替换失效；停止重启不重写；撤销保护人工；下载失败不报成功；生成图区分原文。各自执行证据统一记录在 progress。

### A. 模式开关与每轮冻结

1. **控件位置与外观 [目视]** — composer 起始处应有紧凑的分段控件 `Chat | Agent`，当前档有选中态（`aria-pressed=true`、`data-zchatgpt-mode`）。失败：控件缺失、压住输入框/附件入口、两档无法区分、窄 dock 溢出。
2. **默认档为 Chat [自动]** — 新会话与重启后的未发送标签默认 `Chat`（`presenter.state.mode` 缺省）。失败：默认停在 `Agent`。
3. **切换只影响下一轮 [自动]** — 已发送的历史轮次保持其冻结的 `mode`；切换只改下一条发送。失败：切换后旧消息被改写，或上一轮被重发。
4. **每请求冻结并持久化 [自动]** — 模式在 `sendDraft` 提交前捕获并随请求记录持久化（`Message.mode`、hashVersion 3）；缺 `mode` 的旧记录按其旧 hashVersion 重建，不重分类为 chat。失败：旧记录变 `uncertain`、被改写。
5. **切模式不新建会话、不丢草稿 [自动+目视]** — 在 `Chat`/`Agent` 间往返后仍是同一个会话，历史与草稿都在。失败：出现新会话、草稿清空、文档引用丢失。
6. **未发送标签文案** — 已实现代码在两种模式下未发送标签都是 **New chat**（规格里的 “New agent” 只是“可称”，未实现）；这不属于失败，如实记录即可。

### B. Chat Mode 只读

7. **结构性只读 [自动]** — Chat 档下 `acquire`/`diagram`/其它非 `read` skill 在触达模型、文档读取与任务层之前即被拒绝，文案为 “Switch to Agent…”。失败：Chat 下出现审批/任务/写意图或任何 Zotero 写入。
8. **任务/采集面隐藏 [自动]** — Chat 档下任务面板与采集目标不渲染（`visibleTasks` 为空）。失败：Chat 下仍显示待审批任务。
9. **不触达 Agent 基础设施 [自动]** — `chat/**` 不 import `core/tasks` 或 `zotero/actions`（dependency-boundaries 断言）。失败：边界断言变红。
10. **真实库只读 [目视]** — Chat 下问答不应在 Zotero 库/PDF/标注产生任何写入。失败：出现新标注/高亮/条目/文件改动。（本轮未在真实库尝试写操作，只能你目视。）

### C. Agent Mode 动作与审批

11. **Agent 技能可达 [目视]** — 切到 `Agent` 后 `annotate`/`acquire` 等不再被第 7 条的拒绝阻断，进入候选/任务流程。失败：Agent 档下仍被 “needs Agent mode” 拒绝。
12. **审批/账本/撤销 [目视·未宿主验证]** — 写入须经任务级审批、可撤销、不覆盖后续人工编辑。失败：未审批即写入、撤销不可用或覆盖人工编辑。（`--context` 不发模型、不写库，审批与真实写入**未在宿主验证**。）
13. **模式不授予权限 [自动+目视]** — `Agent` 只是路由；第三方 skill 不能授予权限，写入仍需显式批准。失败：切到 Agent 即自动执行写操作。

### D. 当前 PDF 隐式上下文显示

14. **无需上传 [自动]** — 打开 PDF 后无需手动附加，上下文默认指向当前附件。失败：必须手动附加才有上下文。
15. **实际本地读取 [自动]** — 显示 reader 实际读到的书目卡片与“读完 N 页”一类状态；未读不谎称已读。失败：无读取却显示已读、分母造假。（`--context` 已核对两页抽取与页标签 `i`/`1`、自动全文准备。）
16. **来源与返回 [自动]** — 无引用时来源项隐藏；有引用时显示页标签/`p.` 并可点回该页。失败：指向错误页、点回不导航。（`--context` 已核对 hidden / points-at-selected-page / returns-to-cited-page。）
17. **范围与缺口诚实 [目视]** — 指定页范围及未覆盖/空白/失败页如实显示。失败：静默截断却声称全文。

### E. 会话/历史跨模式续用

18. **同一会话/上下文/history [自动]** — 只有一套 `ConversationPresenter`、`ReaderContext`、conversation history；切模式不新建。失败：出现第二套 session/context。
19. **跨模式复用先前对话 [目视]** — 在 Chat 问“哪些段落最重要”，切到 Agent 说“高亮这些段落”，Agent 复用先前对话与文档引用而非从零开始。失败：上下文丢失、重头开始。
20. **按会话保存草稿/滚动 [自动+目视]** — 关闭 view 不结束任务；切附件/会话不串草稿。`--context` 已核对草稿保持、开关保持当前页、同名附件隔离、附件切换。失败：丢草稿、串会话、跳页。

### F. 已知风险宿主区（重构期未观察）

21. **真实 IME [目视·已知风险]** — 中文输入法组合期间不误发送、不抢焦点；组合中的后台回答不打断输入。失败：组合态 Enter 直接发送、切模式打断 IME。
22. **焦点 [目视·已知风险]** — 模式控件可键盘到达，切模式后焦点留在合理位置且选中态可见。失败：焦点丢失、Tab 掉出 dock。
23. **滚动锚点 [目视·已知风险]** — 切模式/附件、关闭重开后保持当前 PDF 坐标锚点（`--context` 已核对脚本层关闭/重开保持当前页）。失败：跳页/跳段。
24. **原生缩放 [目视·已知风险]** — 模式控件不改变 PDF 缩放；PDF 缩放与聊天字号相互独立（`--context` 已核对脚本层独立）。失败：切模式触发缩放、字号联动。
25. **布局/主题/窄窗 [目视·已知风险]** — 窄 dock、深浅主题、大字号下模式控件不溢出、不遮挡 composer。失败：控件被裁切或遮挡输入。
26. **可访问性/减少动态效果 [目视]** — 尊重 reduced-motion；状态不只靠颜色；图标有名称。失败：动效不受控、仅颜色区分。
